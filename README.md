# 🧠 Brain Tumor Detection using Deep Learning

## Overview

A deep learning system that classifies brain MRI scans into four
categories using transfer learning. The trained model is served
through a simple Streamlit web app where you can upload an MRI
image and get an instant prediction with confidence scores.

This project was built to go from raw MRI images to a trained
model to a usable web app, and it's meant to be run end to end on
a regular laptop (CPU is fine).

## Features

- Transfer learning on top of **MobileNetV2** pretrained on ImageNet
- Data augmentation (rotation, zoom, shift, shear, flip) to reduce overfitting
- Training callbacks: `EarlyStopping`, `ReduceLROnPlateau`, `ModelCheckpoint`
- Automatic evaluation after training: accuracy/loss curves, confusion matrix, classification report
- Streamlit UI with image upload, prediction button, confidence score and per-class probability bars
- Graceful handling of invalid uploads and a missing/untrained model

## Dataset

The model is trained on a brain MRI dataset with four classes:

- Glioma
- Meningioma
- Pituitary
- No Tumor

The dataset is not included in this repository because of GitHub file size limits.
Download the Brain Tumor MRI dataset from Kaggle and place it inside

```
dataset/
├── Training/
│   ├── glioma_tumor/
│   ├── meningioma_tumor/
│   ├── no_tumor/
│   └── pituitary_tumor/
└── Testing/
    ├── glioma_tumor/
    ├── meningioma_tumor/
    ├── no_tumor/
    └── pituitary_tumor/
```

`preprocess.py` picks up class names automatically from these
folder names, so nothing needs to be hardcoded — if you swap in a
dataset with differently named class folders, it'll still work.

## Usage

**1. Train the model** (downloads MobileNetV2's ImageNet weights the
first time, so you'll need an internet connection for this step):

```bash
python train.py
```

This trains the model, saves the best version to
`models/brain_tumor_model.keras`, writes `models/class_indices.json`,
and saves the accuracy/loss curves and confusion matrix to `images/`.

**2. Run the web app:**

```bash
streamlit run app.py
```

Open the local URL Streamlit prints in your browser, upload an MRI
image, and click **Predict**.
